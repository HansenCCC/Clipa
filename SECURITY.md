# Security

Clipa handles clipboard content, which can include sensitive information.

Please do not post passwords, tokens, clipboard databases, or confidential
documents in public issues. For a security report, use GitHub's private
vulnerability reporting feature when available, or contact the maintainer through
the support link on the Mac App Store listing. Share a minimal reproduction using
synthetic data and describe the affected version.

Source builds leave the optional startup statistics endpoint unset. Clipboard
content is stored locally. See the README for the scope of this statement and the
separate privacy policy for the distributed Mac App Store build.
